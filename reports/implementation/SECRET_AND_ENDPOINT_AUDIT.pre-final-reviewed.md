## Issuer correction

Kong's earlier default was a production hostname. `_mint_passport_jwt` places the issuer in a signed identity claim, and Payouts logs include that claim. It is not a URL dereferenced by the inspected verification path. Kong's source default and explicit Compose environment now use `https://identity.arena.invalid`; the replay1 capture confirms that running override. This intentionally differs from production identity while preserving the configured key identifier, generated signing key, RS256 algorithm and validity timestamps.

Pinned verification evidence is Payouts `pkg/passport/handler.go:63–79`, Passport SDK `github.com/razorpay/goutils/passport/v3@v3.4.0/handler.go:52–80` and `passport.go:27`, and the effective `github.com/golang-jwt/jwt@v3.2.2+incompatible/claims.go:32–59` standard time validation. The audit did not restart the stack. Functional acceptance belongs to the replay reports; a clean secret scan does not imply payout acceptance or successful DNS/egress controls.

## Interpretation and remaining limits

Raw matches are not automatically secrets. Explicit arena fixture credentials trace to checked-in templates; Splitz identifiers, request hashes, UUID idempotency keys and inherited public GPG fingerprints have field/type evidence. MongoDB SCRAM values have cryptographic generated-origin evidence, and LocalStack's test key has certificate/public-key evidence. Binary findings require exact source-constant and immutable-file-hash checks, recorded separately. Fresh-input consistency supports arena origin but is not an external attestation of historical randomness.

The remaining limits are rotated-away/earlier/future logs, the unused generated Mozart volume, protected MongoDB session metadata, Redis databases outside configured DB0, in-memory SQS payloads, datastore/substitute image root filesystems, and nonprintable, encrypted or compressed secret encodings. Logical snapshots and decoded Kafka payloads do not establish that every database or index page is free of old or hidden data. Public bank metadata, service source and dependencies intentionally remain real reference inputs; synthetic applies to arena customer fixtures and local credentials.

The last metadata capture predates the final regeneration/boot. Its configuration difference and diagnostic hostname classifications must be refreshed before claiming current endpoint/configuration acceptance. Historical evidence must retain its original scope and result.
