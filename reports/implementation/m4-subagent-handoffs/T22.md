## Generator design
- Stdlib only (host python 3.14): `json`, `csv`, `html`, `re`, `subprocess`, `datetime`,
  `argparse`, `html.parser`. No third-party deps, no network.
- Emits ONE self-contained static HTML: inline CSS + a tiny inline JS (expand/collapse-all).
  Zero external/CDN asset references — renders by opening the local file.
- Paths resolved relative to the script location (repo root = two dirs up), so it is
  location-independent. Evidence links in the page are **relative** from
  `reports/implementation/` so they resolve when the HTML is opened in place.
- **Graceful degradation:** every artifact is loaded through a safe loader that records
  `present | dry-run | absent` and returns `None` on missing/parse-fail. Each section and
  KPI tile renders `"pending"` instead of crashing when its source is absent. All 16
  sources are tracked and listed in the "Evidence links & sources" section.
- **Acceptance handling:** prefers committed `m4-direct-e2e-acceptance.json`. If its
  `dry_run` flag is true it is labelled **DRY-RUN** in the header, footer and gate section.
  If the committed JSON is absent, the generator self-runs
  `python3 RED_LOOP/surface/m4_acceptance.py --dry-run --out <tempfile>` into a temp path,
  reads that, labels DRY-RUN, and deletes the temp file.
- **Validation (in `main()` before write):** (1) feeds output through `html.parser` to
  catch malformed markup; (2) regex-greps for `src=/href="http(s)://` and `url(http(s)://`
  and aborts (exit 2) if any external asset reference is present; (3) prints size and all
  KPI values.

## How to regenerate at finalize
Run from repo root: `python3 RED_LOOP/surface/m4_dashboard.py`
(optional `--out PATH`, `--print-kpis`). Once the coordinator produces a non-dry-run
`m4-direct-e2e-acceptance.json` (dry_run=false, accepted possibly true, G70/G55/G70–G74
resolved) and the final soak JSON lands under `RED_LOOP/runs/*/`, re-running picks them up
automatically: the header flips from DRY-RUN to LIVE, the accepted badge and egress tile
update, and all KPIs recompute. No code change needed. The generator is idempotent and
overwrites `m4-dashboard.html` in place.

## Graceful-degradation behavior
Any absent artifact → its KPI tile and section read "pending" (amber, with icon); the
source row shows `absent`. If the committed acceptance JSON is missing entirely, a
self-run dry-run is used and clearly labelled. No absent file causes a crash.
