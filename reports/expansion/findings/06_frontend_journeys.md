## 1. Summary (≤10 lines)

1. `x` (React SPA, `x/ARCHITECTURE.md:7`) has **~45 top-level route groups** (`x/src/js/views/Routes/data.js:385-861`) spanning 16 product areas; every API call goes to `apiHost` = `https://dashboard.razorpay.com` and is rewritten to `/merchant/api/{mode}<path>` (`x/src/js/api/api.js:63-67,173`) — i.e. the **dashboard PHP host proxies to the monolith**; the SPA never talks to a service host directly (except Axis co-branded org host, `x/config.js:290`).
2. Biggest non-payout surfaces by code/API volume (OBS, `x/src/js/api/*`): **Vendor Payments / Source-to-Pay** (invoices, PO, GRN, items, advances, vendor portal, GST-ITC, TDS on line items — ~120 endpoints under `/vendor-payments/*` + `/vendor_experience/*`), **Accounting integrations** (~60 endpoints under `/accounting-integrations/*`), **Current-account onboarding** (`/merchant/banking_application/*`, `/bas/*`, `/mob/*`, `/banking_accounts*`, `/booking/slot*`), **Tax payments** (`/tax-payments/*`, `/tds-payments/*`, `/compliance_settings/*`), **Team/roles/user-groups/budgets/cost-centers** (`/xperience/*`, `/cac/*`), **Account statement** (`/transactions_banking`, `/banking_account_statement/generate`), **Reports/Finance-X** (`/reporting/*`, `/business-reporting/*`), **Bill payments (BBPS)** (`/x-bill-payments/service/*`), **Receivables** (`/accounts-receivable/service/*`, `/customers`, `/invoices`).
3. **Corporate Cards, BNPL, Amazon instant-settlement, credit-bureau and Loans routes are commented out as deprecated** (`x/src/js/views/Capital/Routes.tsx:55-67` citing Slack thread `C0123GJPYCE/p1735023718541279`; `x/src/js/views/Routes/Routes.js:740-750`). Only Capital **Line of Credit / Cash Advance** remain routed (`Routes.tsx:53-54`) and are served by federated remotes from `cdn.razorpay.com/capital/...` (`x/src/js/bootstrap.ts:45-48`) hitting twirp `/los/service/...`, `/loc/service/...`, `/capital_bnpl/service/v1`, `/capital_cards/service/v1`, `/capital_collections/service/v1`.
4. **Payroll is not in-app**: `/payroll` renders a marketing page linking to `https://payroll.razorpay.com/signup` (`x/src/js/views/Payroll/Payroll.tsx:54,63`); `/xpayroll-connect` is an `ExternalRedirect` to `${xpayrollHost}/sso?integraterx=1` (`x/src/js/views/Routes/Routes.js:1404-1408`; prod host `https://payroll.razorpay.com`, stage `opfin.np.razorpay.in` — `x/config.js:302,146`).
5. `xperience` BFF is gRPC+grpc-gateway; protos are fetched from `razorpay/proto` and gitignored, so REST paths are UNK except workflow/collection-agent callbacks. Its 144 gRPC methods cover **bulk payouts (36), budgets/petty-cash (29), groups/users (29), cost centers (14), paywall (10), statements (1), reports (1), payout downtimes (2), collection agent (3)** — no cards/payroll/tax/capital/onboarding (`parts06/xperience.md §1,§3`).
6. Public contract (`markdown-docs`) exposes only **7 resources / 24 endpoints / 22 webhook events** for X (contacts, fund accounts, FAV, payouts, payout links, transactions, banking_balances); tax, vendor, cards, capital, payroll, CA onboarding, accounting, reports, roles are **dashboard-only** (`parts06/docs.md §1a,§2`). MCP server has 2 read-only payout tools.
7. Roles observed in `x`: `owner, admin, operations, view_only, finance, finance_l1, finance_l2, finance_l3, chartered_accountant, vendor, petty_cash_employee` (`x/src/js/modules/constants.ts:396-427`); ~90 X permission strings in `x/src/js/views/xtra/Can/permission.js:240-435`.
8. Strongest adjacent-domain signals from this pass: **Vendor Payments/S2P (very strong)**, **Accounting integrations (strong)**, **Current-account onboarding (strong)**, **Tax payments/TDS compliance (strong)**, **Team/expense-management via xperience (strong)**, **Account statements/reports (medium)**, **Capital LOC (medium, winding down)**, **Cards (weak — deprecated in x)**, **Payroll (separate product, only SSO link)**.
